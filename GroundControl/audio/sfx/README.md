# audio/sfx — sound effects

Drop files here named exactly as below (`.ogg`, `.wav` or `.mp3`).
Missing files are fine: AudioManager synthesizes a tiny placeholder beep instead.

| file name        | when it plays                                   |
|------------------|-------------------------------------------------|
| ui_click         | buttons, choices                                |
| ui_hover         | menu hover, A/D station switch                  |
| radio_beep       | incoming transmission / mission brief           |
| radio_static     | a dialogue starts, intro card                   |
| typewriter       | text being typed on the radio log (very short)  |
| alarm            | crisis start, low oxygen / power warnings       |
| phone_ring       | a fax arrives                                   |
| fax              | opening the fax station                         |
| paper            | new card discovered, fax answered               |
| knock            | a colleague appears at the hall window          |
| switch           | system levers, repair steps                     |
| card_pin         | card pinned to the cork board                   |
| string_ok        | correct deduction                               |
| string_fail      | wrong string / wrong repair step                |
| achievement      | achievement toast                               |
| crisis_ok        | crisis solved, mission success                  |
| crisis_fail      | crisis failed, mission failed                   |
| nav_ok           | Mia sent to the right grid cell                 |
| nav_fail         | wrong grid cell                                 |
| signal           | the mysterious voice / ending                   |
